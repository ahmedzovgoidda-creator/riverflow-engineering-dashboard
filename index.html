УЧЕБНЫЙ РАСЧЁТ ВЗАИМНОГО ВЛИЯНИЯ

Сваи работают не поодиночке.

Инструмент оценивает дополнительную осадку каждой сваи от соседних нагруженных свай по формулам (7.40)–(7.42). Главная ловушка варианта: нельзя считать осадку группы простым делением общей нагрузки на число свай и игнорировать взаимное влияние.

01 / ПАРАМЕТРЫ ГРУНТА И ГРУППЫ

Общие исходные данные

G₁ — осреднённый модуль сдвига в пределах длины сваи; G₂ — модуль сдвига нижележащего массива. ν₁ и ν₂ — коэффициенты Пуассона. l′ берётся из расчётной модели одиночной сваи. Не подменяйте исходные данные произвольными значениями.

02 / СВАИ И НАГРУЗКИ

Положение, нагрузка и осадка одиночной сваи

Укажите координаты осей свай (м), распределённую вертикальную нагрузку Nⱼ (кН) и осадку одиночной сваи s(Nᵢ) (мм), рассчитанную отдельно по формуле (7.34).

Для малой группы по п. 7.4.1: не более 25 висячих свай. Для n > 25 требуется другая расчётная схема (условный фундамент по пп. 7.4.8–7.4.11).

03 / ПРЕДЕЛЬНОЕ ЗНАЧЕНИЕ

Критерий сравнения

Введите предел из проектного задания или применимого норматива для конкретного сооружения. Универсальное значение здесь не задаётся.

04 / РЕЗУЛЬТАТ

Инженерное заключение

Заполните данные свай и нажмите «Рассчитать».
НОРМАТИВНАЯ ЛОГИКА

Формулы взаимодействия

δᵢⱼ = 0,17 · ln(kᵥG₁l′ / (2G₂aᵢⱼ)), если аргумент больше 1; иначе δᵢⱼ = 0.

Формула (7.41), где aᵢⱼ — расстояние между осями свай i и j.

sᵢ = s(Nᵢ) + Σ [δᵢⱼ · Nⱼ / (G₁l′)], j ≠ i.

Формула (7.42). Взаимодействие соседних свай добавляется к осадке одиночной сваи.

Нагрузка N в нормативной формуле задаётся в МН; в интерфейсе ввод кН, автоматический перевод: 1 кН = 0,001 МН. Результат пересчитывается в мм.

ГРАНИЧНАЯ ЛОВУШКА

Не делите нагрузку и не забывайте взаимодействие

Даже если для предварительной схемы гибкого ростверка принимается одинаковая нагрузка Nср = Nd/n, осадка i-й сваи по (7.42) включает добавки от остальных свай. Для жёсткого ростверка принимается одинаковая осадка всех свай. Распределение усилий для окончательного расчёта уточняется совместным расчётом.

Учебный инструмент, не заменяет инженерно-геологические изыскания, расчёт одиночной сваи, совместный расчёт системы «сооружение–ростверк–сваи–грунт» и проверку всех предельных состояний.
