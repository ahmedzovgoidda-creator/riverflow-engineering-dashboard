# Инженерный помощник — ПЗ №28, вариант 16

Учебный веб-инструмент для расчёта осадки малой группы висячих свай с учётом взаимного влияния свай через грунт.

**Автор:** Мальцагов Саид-Ахмед, группа 1132.

## Что реализовано

- Ввод характеристик грунта: G₁, G₂, ν₁, ν₂ и расчётного параметра l′.
- Ввод координат осей свай, вертикальной нагрузки Nⱼ и осадки одиночной сваи s(Nᵢ).
- Расчёт коэффициента kᵥ по формуле (7.37).
- Расчёт коэффициентов взаимодействия δᵢⱼ по формуле (7.41).
- Расчёт осадки i-й сваи с учётом соседних свай по формуле (7.42).
- Проверка результата по допустимой осадке, которую пользователь задаёт из проекта или задания.
- Валидация исходных данных и блокировка некорректного ввода.
- Отправка исходных данных и результатов в Google Sheets через Google Apps Script.

## Нормативная основа

СП 24.13330.2021 «Свайные фундаменты», раздел 7.4, пункты 7.4.1, 7.4.4–7.4.5, формулы (7.37), (7.40)–(7.42).

Учтено Изменение № 2 к СП 24.13330.2021, введённое 29 августа 2026 года. Изменение уточняет условия применения расчётной схемы для малых и больших групп и редакцию отдельных положений 7.4.1 и 7.4.5.

## Граничная ловушка варианта 16

Нельзя просто разделить суммарную нагрузку на число свай и остановиться на этом. Взаимное влияние свай должно быть учтено через добавочные осадки от остальных свай по формулам (7.41) и (7.42). При этом для предварительной схемы гибкого ростверка допускается равное распределение нагрузки, но это не отменяет расчёт взаимодействия.

## Важные ограничения

- Инструмент предназначен для учебной предварительной оценки малой группы висячих свай (до 25 свай).
- Осадка одиночной сваи s(Nᵢ) вводится как исходное значение после отдельного расчёта по формуле (7.34); этот модуль пока не автоматизирует полный расчёт одиночной сваи.
- l′ и характеристики грунта должны приниматься по инженерно-геологическим данным и соответствующей расчётной модели.
- Допустимую осадку задаёт проект/задание; универсальный предел в приложении не зашит.
- Большие свайные поля требуют другой расчётной схемы (условный фундамент по 7.4.8–7.4.11) или геотехнической модели.
- Приложение не заменяет инженерно-геологические изыскания, совместный расчёт сооружения, ростверка, свай и грунта, а также проверку всех предельных состояний.

## Google Sheets

Форма отправляет JSON на настроенный Google Apps Script endpoint в режиме `no-cors`. В этом режиме браузер не может подтвердить успешную запись. После отправки обязательно откройте Google Таблицу и проверьте, что новая строка появилась в листе «Журнал».
