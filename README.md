# RIVERFLOW — Engineering Dashboard

Учебный инженерный дашборд (вариант 3): транспортные расчёты, регистрация поступления материалов и предварительная проверка сужения устойчивого русла мостовым переходом.

## Состав проекта

1. **Пропускная способность** — P = 3600 / t × K.
2. **Коэффициент загрузки** — Z = N / P.
3. **Интервал автобусов** — время оборота T = 2L / V × 60, интервал I = T / N.
4. **Поступление материалов** — дата, материал, количество и единица измерения; количество должно быть больше нуля.
5. **Сужение русла** — учебная проверка условия Bсвет ≥ Bуст по пункту 5.28 СП 35.13330.2011.
6. **Сводный отчёт** — результаты выполненных расчётов.

## Google Sheets

Формы отправляют JSON на подключённый Google Apps Script endpoint. Используется режим no-cors, поэтому браузер не может подтвердить факт записи. После тестовой отправки обязательно проверьте лист «Журнал» в Google Таблице.

## Ограничения

Проверка сужения русла оценивает только одно условие, приведённое в учебном проекте. Это не полный гидравлический расчёт мостового перехода и не замена инженерным изысканиям. Актуальность применяемой редакции СП нужно подтвердить по официальному реестру перед использованием в реальном проектировании.
